## 📦 How to Install

Each skill can be installed via:

```bash
npx skills add <repo-url> --skill <skill-name>
```

> **📌 Source:** Skills are discovered on [skills.sh](https://www.skills.sh) — browse the full Flutter collection at [skills.sh/flutter/skills](https://www.skills.sh/flutter/skills)
