## 📦 How to Install

Each skill can be installed via:

```bash
npx skills add <repo-url> --skill <skill-name>
```

---

## 🪨 Caveman

```bash
npx skills add https://github.com/juliusbrussee/caveman --skill caveman
```

> *A skill for writing dead-simple, primitive code — no over-engineering, no abstractions, just straightforward solutions.*
